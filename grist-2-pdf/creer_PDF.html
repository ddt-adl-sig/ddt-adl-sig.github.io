Convertir le contenu d'une colonne (au format HTML) en PDF
Enregistrement du fichier PDF :
-- soit dans un fichier sur votre ordinateur (il vous demandera où l'enregistrer)
-- soit dans une colonne pièce jointe de la table associée à ce widget (indiquer la colonne pièce jointe dans les options de la vue)

Mise en page par défaut : format A4, orientation portrait, marges 20mm.
Vous pouvez définir vos réglages dans des colonnes de la table et les indiquer dans les options du widget (panneau de droite).

   
{Prenom} {nom}
{date}
{organisme.raison}
Toulouse, le {today}
